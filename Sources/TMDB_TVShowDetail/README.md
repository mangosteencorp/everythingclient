# TMDB_TVShowDetail

The TMDB TV show detail screen: header, poster, overview, genres, creators, details, where-to-watch providers, seasons
and a "Similar" row. The entry point is `TVShowDetailView(tvShowId:apiService:)`, which takes any `TMDBAPIRequesting`
and expects a `ThemeManager` as an `@EnvironmentObject`; `TMDB/Navigation/TMDBNavigationDestinations.swift` builds it
that way. It is SwiftUI: the screen's load state lives in a nested `TVShowDetailView.Store` (an `ObservableObject` held
with `@StateObject`), the watch providers section keeps its own `@State`, and the Similar row uses an `@Observable`
`SimilarTVViewModel` (iOS 17+). Dependencies (from `Package.swift`): `CoreFeatures`, `TMDB_Shared_Backend`,
`TMDB_Shared_UI`, `Shared_UI_Support`.

## Tests
